# Johnson Prem B | Mechanical Design Portfolio

A responsive, single-page portfolio built with HTML, CSS, and vanilla JavaScript. Designed for GitHub Pages.

## Run locally
Open `index.html` in a browser.

## Deploy to GitHub Pages
1. Create a GitHub repository, for example `johnson-prem-portfolio`.
2. Upload the contents of this folder to the repository root. Keep the `assets` folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. The site URL will appear in the Pages settings.

## Personalise before publishing
- Check the contact details in `index.html` and `script.js`.
- Add your GitHub or LinkedIn links if you want them visible.
- Project descriptions are written from the resume and supplied project images. Add dimensions, tools, outcomes, and verified project specifics where you have them.
- The Inline Pipe Inspection Robot description follows the resume. Some other project names and descriptions are inferred from the images and should be edited if the project details differ.

## Files
- `index.html`: page structure and project cards
- `style.css`: layout, responsive styling, animations
- `script.js`: animated canvas background, project filters, and detail modals
- `assets/`: uploaded project images
